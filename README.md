# Zoqelle — Luxury Artisanal Bakery E-Commerce Platform

Zoqelle is a modern full-stack e-commerce platform designed for a luxury artisanal bakery. It provides a premium online shopping experience where customers can explore handcrafted cakes and pastries, manage their cart, place orders, and track their purchases.

The platform also includes a dedicated admin dashboard for managing products, categories, inventory, customer orders, and sales data.

## Features

* Luxury editorial-style e-commerce storefront
* Product browsing and category filtering
* Product details with pricing, ingredients, reviews, and stock availability
* Persistent shopping cart
* Stock validation and shipping progress
* Streamlined checkout experience
* Customer profile and order management
* Order tracking with status progression
* Email/password and Google authentication
* Admin dashboard for product and inventory management
* Order lifecycle management
* Sales and revenue overview
* Role-based access control
* Responsive design for desktop and mobile devices

## Design

Zoqelle features a warm, elegant visual identity inspired by luxury bakery and editorial design. The interface combines refined typography, a soft cream and burgundy color palette, muted gold accents, subtle animations, elevated surfaces, and responsive layouts to create a premium shopping experience.

## Project Highlights

Zoqelle demonstrates practical full-stack development through a complete e-commerce workflow, including authentication, product management, inventory handling, cart functionality, checkout, order tracking, database relationships, role-based authorization, and administrative management.

The project was built to showcase the ability to develop a polished, user-focused application while working with modern frontend technologies and a managed PostgreSQL backend.
